# REROUTE 매칭안 화면 인계서

> 현재 상태: 초기 시안을 바탕으로 구현과 QA를 마친 화면의 기준을 기록합니다. 구현 과정에서 데이터 일관성과 모바일 접근성을 보완했기 때문에 최초 시안과 일부 수치 및 동작이 다릅니다.

## 화면 목적

오피스 이전 자산 214개의 수요처, 회수 금액, 비용 절감, 재사용 성과와 수거 일정을 한 화면에서 비교하고, 의사결정 기준을 충족한 매칭안을 확정합니다.

## 기준 시안

- 파일: `reroute-marketplace-final.png`
- 기준 해상도: 1440 × 1024
- 서비스 성격: 독립형 B2B 순환 자산 매칭 마켓플레이스
- 핵심 행동: `매칭안 확정`

## 레이아웃

- 좌측 탐색: 190px 고정
- 본문: 24px 외곽 여백, 16px 섹션 간격
- 핵심 지표와 의사결정 카드: `minmax(0, 1fr) 340px`
- 자산 요약과 추천 매칭안: `440px minmax(0, 1fr)`
- 표 행 높이: 78px, 헤더 44px, 합계 54px
- 1280px 미만에서는 자산 요약과 추천 매칭안을 한 열로 배치합니다.
- 900px 이하에서는 모바일 탐색 메뉴와 가로 스크롤 표를 제공하고, 390px 화면에서도 주요 정보와 확정 동작을 사용할 수 있게 합니다.

## 데이터 및 계산 규칙

- 현금 회수액: `720 + 640 + 280 + 200 = 1,840만 원`
- 비용 절감: `0 + 0 + 0 + 300 = 300만 원`
- 순경제효과: `1,840 + 300 = 2,140만 원`
- 재사용 자산: `72 + 64 + 50 = 186개`
- 재사용률: `186 / 214 = 86.9%`
- 재활용 28개는 재사용률 분자에서 제외한다.
- 수거 횟수는 고유 날짜 `9월 8일`, `9월 10일`, `9월 12일`의 3회다.
- 금액은 서버에서 만 원 단위 정수로 계산하고 화면에도 만 원 단위로 표시합니다.

## 상호작용과 상태

- `입찰 11건 보기`: 전체 입찰과 매칭에 사용된 입찰을 비교하는 화면으로 이동합니다.
- `조건 다시 계산`: 최대 수거 횟수, 최소 현금 회수액과 최소 재사용률을 수정하는 대화상자를 엽니다.
- `매칭안 확정`: 요약을 확인한 뒤 서버의 확정 결과가 돌아올 때까지 기다립니다.
- 로딩 중에는 표 구조를 유지하는 자리 표시 화면을 보여줍니다. 계산 결과가 없으면 자산과 입찰을 확인할 다음 행동을 안내하고, 오류가 발생하면 다시 시도할 수 있게 합니다.
- 권한이 없는 사용자는 비활성화된 `확정 권한 요청` 버튼을 봅니다.

## 접근성과 품질 기준

- 본문과 배경 대비 4.5:1 이상, 포커스 링 2px 이상
- 색상만으로 통과 상태를 전달하지 않고 아이콘과 `통과` 텍스트를 함께 표시
- 모든 아이콘에 접근 가능한 이름 제공, 장식 이미지는 빈 대체 텍스트 사용
- 금액과 비율은 스크린리더에서 단위까지 읽히도록 별도 레이블 제공
- 확정 요청은 중복 요청 방지 키를 사용해 한 번만 처리하고 감사 로그를 남깁니다.
