# REROUTE 매칭안 화면 핸드오프

## 화면 목적

오피스 이전 자산 214개의 수요처, 회수 금액, 비용 절감, 재사용 성과, 수거 일정을 한 화면에서 비교하고 의사결정 기준을 충족한 매칭안을 확정한다.

## 기준 시안

- 파일: `reroute-marketplace-final.png`
- 기준 해상도: 1440 × 1024
- 서비스 성격: 독립형 B2B 순환 자산 매칭 마켓플레이스
- 핵심 행동: `매칭안 확정`

## 레이아웃

- 좌측 탐색: 190px 고정
- 본문: 24px 외곽 여백, 16px 섹션 간격
- KPI와 의사결정 카드: `minmax(0, 1fr) 340px`
- 배치 요약과 추천 매칭안: `440px minmax(0, 1fr)`
- 표 행 높이: 78px, 헤더 44px, 합계 54px
- 1280px 미만에서는 배치 요약을 접을 수 있는 상단 패널로 전환한다.
- 모바일은 본 PoC 검증 범위에서 제외하되, 1024px까지 읽기와 확정 행동을 보장한다.

## 데이터 및 계산 규칙

- 현금 회수액: `720 + 640 + 0 + 200 = 1,560만 원`
- 비용 절감: `0 + 0 + 320 + 300 = 620만 원`
- 순경제효과: `1,560 + 620 = 2,180만 원`
- 재사용 자산: `72 + 64 + 50 = 186개`
- 재사용률: `186 / 214 = 86.9%`
- 재활용 28개는 재사용률 분자에서 제외한다.
- 수거 횟수는 고유 날짜 `9월 8일`, `9월 10일`, `9월 12일`의 3회다.
- 금액은 서버의 정수 원 단위를 기준으로 계산하고 화면에서 만 원 단위로 표시한다.

## 상호작용과 상태

- `입찰 11건 보기`: 매칭 근거가 된 입찰 패널을 연다.
- `조건 다시 계산`: 수거 횟수, 최소 회수액, 기부 및 재활용 제약을 수정하는 드로어를 연다.
- `매칭안 확정`: 요약 확인 후 낙관적 갱신 없이 서버 확정 결과를 기다린다.
- 모든 행은 수요처 상세, 인증 근거, 배정 자산 목록으로 이동할 수 있다.
- 로딩은 표 구조를 유지하는 skeleton, 빈 상태는 조건 재설정 CTA, 오류는 재시도와 오류 식별자를 제공한다.
- 권한이 없는 사용자는 확정 버튼 대신 `확정 권한 요청`을 본다.

## 접근성과 품질 기준

- 본문과 배경 대비 4.5:1 이상, 포커스 링 2px 이상
- 색상만으로 통과 상태를 전달하지 않고 아이콘과 `통과` 텍스트를 함께 표시
- 모든 아이콘에 접근 가능한 이름 제공, 장식 이미지는 빈 대체 텍스트 사용
- 금액과 비율은 스크린리더에서 단위까지 읽히도록 별도 레이블 제공
- 확정 요청은 idempotency key로 중복 제출을 방지하고 감사 로그를 남긴다.
