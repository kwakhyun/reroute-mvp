# 개발부문 인계 문서

## 검증 대상

한 화면에서 자산 배치, 입찰 근거, 순경제효과, 재사용률, 수거 제약을 검토하고 확정하는 경험이 실제 승인 시간을 줄이는지 확인합니다.

## 재사용 가능한 산출물

- Drizzle 스키마, 순차 마이그레이션, 기존 데이터 보존 회귀 테스트
- 결정론적 매칭 엔진과 단위 테스트
- 인증, 조직 멤버십, 프로젝트 역할, 세션 경계
- 요약, 감사 로그, CSV API 계약
- 프로젝트 버전 CAS를 사용하는 재계산과 확정 트랜잭션, 실제 DB 경쟁 테스트
- 사용자 행동 이벤트 정의
- 반응형 화면과 디자인 토큰
- 자산과 검증 증빙 포함 입찰 CSV 가져오기, 수거 상태 전이, 외부 정산 확인 상태
- CI와 컨테이너 빌드

## 확정된 도메인 결정

- 금액은 만 원 단위 정수로 저장합니다.
- 추천안은 전체 자산 수량을 정확히 배정해야 합니다.
- 각 자산군은 검증된 파트너 입찰 하나로 전체 수량을 배정해야 합니다.
- 확정 전 초안은 다시 계산할 수 있고 확정 후에는 잠깁니다.
- 현금 회수액과 비용 절감액의 합을 순경제효과로 정의합니다.
- 같은 날짜의 수거는 한 회차로 계산합니다.
- 확정은 반드시 감사 로그를 남깁니다.
- 외부 정산 확인은 자금을 이동하지 않으며 결제사 참조값만 기록합니다.
- 프로젝트의 유효 현금 회수 하한은 프로젝트 설정액과 자산별 회수 기준액 합계 중 큰 값입니다.
- 모든 입찰은 검증자, 검증 시각, 참조값을 가져야 하며 만료된 검증은 매칭 후보에서 제외합니다.

## 한계와 교체 지점

| 현재 MVP | 운영 전환 시 |
| --- | --- |
| 조직 멤버십 기반 프로젝트 격리 | SSO 그룹 동기화와 멤버십 수명주기 |
| 상한이 있는 작은 조합 탐색 | 큐 기반 비동기 제약 최적화 서비스 |
| 데모 계정 | OIDC SSO, MFA, 사용자 수명주기 |
| 외부 정산 상태 수동 대조 | 결제사 계약, 서명된 웹훅, 이중부기 원장 |
| 자산 CSV와 정제된 입찰 데이터 | 대용량 엑셀 수입, 검증 큐, 원본 보존 |
| 단일 앱 트랜잭션 | 아웃박스와 이벤트 기반 운영 인계 |
