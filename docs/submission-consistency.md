## 동시성 설명의 검증 범위

PDF 5쪽의 SQLite 경쟁 테스트는 실제 DB에서 CAS와 트랜잭션을 확인한 기록입니다. 다만 개선 전 테스트는 서비스의 SQL 흐름을 테스트 안에 별도로 구현했으므로, 실제 서비스와 브라우저 사이의 모든 경계 조건까지 검증했다는 뜻으로 해석하면 안 됩니다. [당시 테스트 소스](https://github.com/kwakhyun/reroute-mvp/blob/bb506103ba28148ea6fe3aad7baea357c4f1ffd7/src/server/db/concurrency.test.ts)에서도 이 범위를 확인할 수 있습니다.

후속 검토에서는 확인창을 연 뒤 다른 사용자가 재계산하면 검토하지 않은 최신 배분안을 확정할 수 있는 경로를 발견했습니다. 현재는 사용자가 검토한 배분안 ID와 프로젝트 버전을 서버에서 다시 검사합니다. 실제 서비스 호출로 테스트를 바꾸고, 읽기와 트랜잭션 사이의 재계산, 동일 요청 재시도, 로컬 파일 DB 경쟁과 실패 후 복구를 검증했습니다. 이 수정과 테스트 확대를 제출 당시 구현에 소급해 주장하지 않습니다.
