# 신규 사업 실험 계획

## 문제 정의

오피스 이전과 폐점 때 자산 담당자는 중고 매입업체, 폐기업체, 기부처, 임직원 판매를 따로 조율합니다. 높은 판매가만 선택하면 수거가 분산되고, 일정을 우선하면 재사용 가능한 자산까지 폐기될 수 있습니다. 의사결정 근거가 여러 문서에 흩어져 승인도 늦어집니다.

## 초기 고객

- 50개 이상의 사무 자산을 한 번에 처분하는 100인 이상 기업
- 오피스 이전, 통폐합, 리뉴얼을 3개월 안에 앞둔 총무 또는 자산 담당자
- 현금 회수뿐 아니라 폐기 비용, ESG 지표, 철수 일정을 함께 책임지는 팀

## 가장 위험한 가설

1. 담당자는 개별 최고가보다 전체 순경제효과를 더 중요한 승인 근거로 사용한다.
2. 재사용률과 수거 횟수를 함께 제시하면 경영진 승인 시간이 줄어든다.
3. 검증된 수요처 네트워크에 대한 중개 수수료 또는 성공 수수료를 지불할 의사가 있다.
4. 입찰을 여러 수요처로 나눠도 세 번 이내 수거라면 운영 부담을 수용한다.

## MVP에서 측정할 퍼널

| 단계 | 이벤트 | 성공 기준 |
| --- | --- | --- |
| 매칭안 노출 | `dashboard_viewed` | 파일럿 담당자 10명 이상 |
| 입찰 근거 확인 | `bids_opened` | 노출 대비 60% 이상 |
| 조건 탐색 | `recalculation_opened` | 노출 대비 30% 이상 |
| 확정 의도 | `confirmation_opened` | 노출 대비 20% 이상 |
| 실제 파일럿 | 운영 인터뷰 | 5개사 중 3개사 이상 |

보조 지표는 첫 화면에서 확정 의도까지 걸린 시간, 재계산 횟수, 기준 미충족 비율, 수거 회차 변경 횟수입니다.

`dashboard_viewed`와 `bids_opened`는 각 페이지 진입을 뜻합니다. 클릭과 페이지 노출을 같은 이름으로 중복 기록하지 않습니다. 파일럿 분석에서는 사용자, 프로젝트, 이벤트 이름을 기준으로 최초 발생 시각을 사용해 퍼널을 계산합니다. 동일 사용자가 새 세션에서 다시 검토한 행동은 재방문 지표로 별도 집계합니다.

```sql
SELECT
  project_id,
  user_id,
  min(CASE WHEN name = 'dashboard_viewed' THEN occurred_at END) AS dashboard_at,
  min(CASE WHEN name = 'bids_opened' THEN occurred_at END) AS bids_at,
  min(CASE WHEN name = 'recalculation_opened' THEN occurred_at END) AS recalculation_at,
  min(CASE WHEN name = 'confirmation_opened' THEN occurred_at END) AS confirmation_at
FROM analytics_events
GROUP BY project_id, user_id;
```

## 수익 가설

- 판매 회수액의 8% 성공 수수료
- 비용 절감액의 10% 성과 수수료
- 대기업용 검수, 운송, ESG 증빙을 포함한 프로젝트 이용료

첫 파일럿은 과금 방식보다 지불 의사와 승인권자의 기준을 확인하는 데 집중합니다.

## 4주 검증 계획

### 1주차

실제 이전 또는 폐점을 앞둔 담당자 10명을 인터뷰하고 최근 처분 자료를 수집합니다. 승인 기준과 현재 소요 시간을 확인합니다.

### 2주차

동일 자산 배치에 대해 수요처 입찰을 수작업으로 확보합니다. 제품에는 정제된 입찰만 넣어 매칭안 검토 경험을 검증합니다.

### 3주차

5개사에 MVP를 제공하고 화면 공유 없이 직접 사용하게 합니다. 행동 이벤트, 질문, 재계산 조건을 기록합니다.

### 4주차

최소 2개 프로젝트에서 실제 수거 의향서 또는 유료 파일럿 합의를 확보합니다.

## 투자 판단

| 결과 | 판단 |
| --- | --- |
| 유료 파일럿 2개 이상, 확정 의도율 20% 이상 | 전담 개발 투자 |
| 사용성 지표는 충족하지만 지불 의사 부족 | 가격과 구매자 재검증 후 2주 반복 |
| 입찰 근거 확인율 40% 미만 | 문제와 정보 구조 재정의 |
| 고객이 개별 최고가만 선택 | 통합 매칭 가설 중단 |

운영 전환 판단에는 거래 실패율, 수거 지연, 개인정보 사고, 미검증 파트너 비율을 반드시 가드레일로 포함합니다.

## 의도적으로 생략한 범위

- 공개 판매자 가입과 실명 인증 자동화
- 결제사 연동과 실제 에스크로
- 운송사 배차 최적화
- 대용량 엑셀 자동 수입과 원본 파일 보존
- LLM 문서 추출과 제안서 자동 생성

이 기능은 매칭안 검토와 확정 의도가 확인된 뒤 순서대로 추가합니다.
