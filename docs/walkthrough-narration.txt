REROUTE는 오피스 이전과 폐점 과정에서 발생하는 유휴 자산을, 의사결정 가능한 제안으로 바꾸는 비투비 순환 자산 매칭 엠비피입니다. 현장의 자산 담당자는 매각가, 폐기비, 재사용 성과, 수거 일정을 서로 다른 문서에서 맞추고, 승인자가 이해할 근거를 다시 만들어야 합니다. 개별 최고가보다 전체 순경제효과와 운영 제약을 하나의 제안에 보여주면, 확정 의도가 높아질 것이라는 가설에서 시작했습니다.

제품 데모는 성수 오피스 이전을 가정한 샘플 자산 이백십사 개와, 검증 정보가 포함된 샘플 입찰 열한 개로 시작합니다. 현금 회수액, 폐기비 절감액, 순경제효과, 재사용률을 한 눈에 비교하고, 해당 수치를 만든 자산별 배분과 파트너 증빙을 함께 확인합니다. 현금 회수 하한, 최소 재사용률, 최대 수거 횟수를 바꾸면 서버에서 매칭안을 다시 계산합니다. 입찰 후보가 자산별 회수 하한을 깨거나, 자산 전체 수량을 채우지 못하면 확정할 수 없습니다. 파트너 검증이 만료된 경우도 동일합니다.

확정 권한이 있는 사용자가 제안을 승인하면, 자산별 배분은 수거 운영으로 인계됩니다. 수거 담당자는 일정, 시간대, 차량, 상태 전이를 기록하고, 외부 정산은 자금을 이동하지 않고 연동 여부와 대조 상태만 기록합니다. 재계산과 확정이 겹치는 경우를 막기 위해, 프로젝트 버전 비교 교환 방식과 데이터베이스 트랜잭션을 적용했습니다. 중복 요청은 멱등성 키로 하나의 결과만 남깁니다. 실제 에스큐엘라이트 트랜잭션을 경쟁시켜, 재계산과 확정 중 하나만 커밋되는지 테스트했습니다.

시스템은 넥스트 제이에스 앱 라우터, 리액트, 타입스크립트로 구현했습니다. 서버 액션과 에이피아이는 제트오드로 입력을 검증하고, 드리즐 오에르엠과 리브에스큐엘은 십육 개의 관계형 스키마로 상태를 저장합니다. 비밀번호는 에스크립트로 해시하고, 데이터베이스 세션, 조직 멤버십, 프로젝트 역할로 최소 권한을 적용했습니다. 다른 조직의 페이지와 에이피아이를 직접 열어도 데이터를 노출하지 않고 사백사로 끝나는지 전체 여정으로 검증했습니다. 깃허브 액션은 린트, 타입 검사, 커버리지, 빌드, 브라우저 여정을 매 변경마다 실행합니다.

다음은 실제 파일럿 전에 의사결정 규칙을 점검한 결과입니다. 중요하게도, 이 수치는 실제 고객 조사나 운영 로그가 아닙니다. 합성 사용자 열 명과 합성 기업 다섯 개사를 가정하고, 고정 시드로 오만 번 반복했습니다. 모든 성공 기준을 동시에 충족할 추정 확률은 십팔 점 팔 퍼센트, 확정 의도와 유료 파일럿 기준을 함께 충족할 추정 확률은 삼십 점 구 퍼센트였습니다. 대표 합성 코호트의 유료 파일럿은 다섯 개사 중 한 개사로, 투자 기준인 두 개사에 미달했습니다. 따라서 제한된 실제 파일럿은 진행하되, 전담 개발 투자는 보류합니다. 실제 다섯 개사에서 지불 의사와 계약 주체를 확인한 후, 유료 파일럿 두 개사와 확정 의도율 이십 퍼센트를 함께 충족할 때만 투자를 재판단합니다.

이 개인 프로젝트의 기여도는 백 퍼센트입니다. 문제 정의, 사업 가설, 제품 범위, 디자인, 프론트엔드, 에이피아이, 데이터베이스, 보안, 테스트, 배포, 문서화를 혼자 완결했습니다. 에이아이 코딩 에이전트는 탐색, 반복 구현, 감사 보조에 사용했습니다. 권한 경계, 트랜잭션, 스키마, 안전 장치와 의사결정 수치는 소스 라인, 실행 테스트, 독립 재계산으로 직접 확인했습니다. 사업성이 확인되면 스키마, 검증 결과, 교체 지점, 제품의 한계를 다른 개발팀이 이어받을 수 있게 정리했습니다.
