REROUTE는 오피스 이전과 폐점 과정에서 생기는 유휴 자산을 결정에 바로 쓸 수 있는 제안으로 바꾸는 B2B 순환 자산 매칭 MVP입니다. 자산 담당자는 매각가, 폐기비, 재사용 성과와 수거 일정을 서로 다른 문서에서 맞춘 뒤, 승인자가 이해할 수 있는 근거를 다시 정리해야 합니다. 개별 최고가 대신 전체 순경제효과와 운영 조건을 하나의 제안으로 보여주면 확정 의도가 높아질 것이라는 가설에서 시작했습니다.

제품 데모는 성수 오피스 이전을 가정한 샘플 자산 214개와 검증 정보가 포함된 입찰 11건으로 시작합니다. 현금 회수액, 폐기비 절감액, 순경제효과와 재사용률을 한눈에 비교하고, 이 수치를 만든 자산별 배분과 수요처 검증 근거를 함께 확인합니다. 최소 현금 회수액, 최소 재사용률과 최대 수거 횟수를 바꾸면 서버에서 매칭안을 다시 계산합니다. 모든 자산을 배정하지 못하거나 자산군별 최소 회수액을 충족하지 못한 입찰은 확정할 수 없습니다. 수요처 검증이 만료된 경우도 마찬가지입니다.

승인 권한이 있는 사용자가 매칭안을 확정하면 자산별 배분이 수거 운영으로 넘어갑니다. 수거 담당자는 일정, 시간대, 차량과 진행 상태를 기록합니다. 외부 정산 화면은 자금을 이체하지 않고, 결제사에서 확인한 입금과 지급 상태만 남깁니다. 재계산과 확정이 겹치지 않도록 프로젝트 버전 확인과 데이터베이스 트랜잭션을 적용했고, 중복 요청에는 같은 결과를 돌려줍니다. 실제 SQLite 트랜잭션을 동시에 실행해 재계산과 확정 중 하나만 반영되는지도 확인했습니다.

시스템은 Next.js 앱 라우터, React와 TypeScript로 구현했습니다. 서버 액션과 API는 Zod로 입력을 검증하고, Drizzle ORM과 libSQL은 16개의 관계형 스키마에 상태를 저장합니다. 비밀번호는 scrypt로 해시하고, 데이터베이스 세션, 조직 멤버십과 프로젝트 역할로 최소 권한을 적용했습니다. 다른 조직의 페이지와 API를 직접 열어도 데이터를 노출하지 않고 404를 반환하는지 전체 여정으로 검증했습니다. GitHub Actions는 린트, 타입 검사, 커버리지, 빌드와 브라우저 여정을 실행합니다.

다음은 실제 파일럿 전에 의사결정 규칙을 점검한 결과입니다. 이 수치는 실제 고객 조사나 운영 로그가 아닙니다. 합성 사용자 10명과 합성 기업 5개사를 가정하고 고정 시드로 5만 회 반복했습니다. 모든 성공 기준을 동시에 충족할 추정 확률은 18.8퍼센트, 확정 의도와 유료 파일럿 기준을 함께 충족할 추정 확률은 30.9퍼센트였습니다. 대표 합성 코호트의 유료 파일럿은 5개사 중 1개사로, 투자 기준인 2개사에 미달했습니다. 따라서 제한적인 실제 파일럿은 진행하되 전담 개발 투자는 보류합니다. 실제 기업 5곳에서 지불 의사와 계약 주체를 확인한 후, 유료 파일럿 2개사와 확정 의도율 20퍼센트를 함께 충족할 때만 투자를 다시 판단합니다.

이 개인 프로젝트의 기여도는 100퍼센트입니다. 문제 정의, 사업 가설, 제품 범위, 디자인, 프론트엔드, API, 데이터베이스, 보안, 테스트, 배포 구성과 문서화를 직접 수행했습니다. AI 코딩 에이전트는 탐색, 반복 구현과 감사 보조에 사용했습니다. 권한 경계, 트랜잭션, 스키마, 안전장치와 의사결정 수치는 소스 코드, 실행 테스트와 독립 재계산으로 직접 확인했습니다. 사업성이 확인되면 다른 개발팀이 이어받을 수 있도록 스키마, 검증 결과, 교체 지점과 제품의 한계를 정리했습니다. REROUTE는 기능 수보다 다음 투자 판단에 필요한 근거를 빠르고 안전하게 만드는 데 집중한 풀스택 제품입니다.
