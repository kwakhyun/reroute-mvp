# REROUTE 디자인 시스템

2026-09-05 기준. 서비스 소개, 로그인, 프로젝트, 자산, 매칭, 입찰, 수거와 정산에 같은 색상과 컴포넌트 규칙을 적용합니다.

## 색상과 글꼴

| 용도 | 값 | 적용 |
| --- | --- | --- |
| 강조 | `#ffda24` | 기본 실행 버튼, 선택한 메뉴, 브랜드 심볼 |
| 본문 | `#242629` | 제목, 본문, 강조 배경 위 텍스트 |
| 보조 텍스트 | `#62666e` | 설명, 레이블, 갱신 시각 |
| 작업 배경 | `#f6f7f9` | 로그인 후 작업 공간 |
| 카드 | `#ffffff` | 표, 입력 폼, 프로젝트와 수거 카드 |
| 구분선 | `#e5e7eb` | 카드 테두리와 표의 행 구분 |
| 옅은 강조 | `#fff7cd` | 진행 상태와 안내 영역 |

글꼴은 로컬로 제공하는 Noto Sans KR을 사용합니다. 제목과 주요 숫자는 굵기로 위계를 만들고, 숫자에는 고정폭 숫자 스타일을 적용합니다. 노란색 면에는 어두운 글자를 사용하며 성공과 오류는 각각 녹색과 적색, 상태 문구를 함께 표시합니다.

## 화면 구성

- 홈: 짙은 안내 바, 흰색 탐색 메뉴, 큰 제목과 제품 미리보기, 세 가지 서비스 소개 카드 순서로 시작합니다. 구현 근거와 가상 분석의 한계는 아래에서 확인할 수 있습니다.
- 로그인: 옅은 노란색 소개 영역과 계정 입력 영역을 나눕니다. 샘플 작업 공간 진입과 초기화는 별도의 동작으로 유지합니다.
- 작업 공간: 흰색 사이드바, 회색 배경, 흰색 카드로 영역을 구분합니다. 프로젝트 목록 상단에는 조회 권한이 있는 프로젝트의 등록 수, 검토 중인 수와 확정 수를 표시합니다.
- 업무 화면: 숫자 요약, 조건 입력, 상세 표, 다음 행동 순서를 유지합니다. 버튼은 기본 높이 48px, 모서리 10px이며 일반 카드는 16px 모서리를 사용합니다.

## 반응형과 접근성

- 모바일에서는 사이드바를 메뉴 버튼으로 엽니다. 닫힌 메뉴는 탭 이동에서 제외하고, 열린 메뉴는 배경 조작을 막으며 닫을 때 버튼으로 포커스를 돌려줍니다.
- 화면 폭에 따라 소개 카드와 업무 표를 세로로 배치합니다. 넓은 표만 내부 스크롤을 제공하고, 실제로 넘칠 때 스크롤 안내와 키보드 포커스를 표시합니다.
- 입력 필드의 아이콘, 테두리와 포커스는 공통 폼 모듈에서 관리합니다. 제목, 레이블과 오류 문구는 색상 없이도 의미를 알 수 있게 유지합니다.
- 모션 감소 설정, 확인창의 포커스 이동, 로딩과 오류 상태, 중복 실행 방지는 기존 동작을 유지합니다.

공통 토큰은 `src/app/globals.css`, 화면별 스타일은 `src/styles`의 CSS Modules에 있습니다. 현재 화면은 [홈 미리보기](../public/product/overview.png)와 [매칭 미리보기](../public/product/matching-preview.png), 검증 범위는 [디자인 QA](../design-qa.md)를 참고하세요.
