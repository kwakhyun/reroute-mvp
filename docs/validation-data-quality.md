# 합성 검증 데이터 품질 판정

판정: **제한 조건으로 공유 가능**

이 자료는 제품 의사결정 규칙의 재현성을 설명하기에는 충분하지만, 고객 수요나 사업성을 증명하는 근거로는 사용할 수 없습니다.

## 검사한 항목

| 항목 | 결과 | 근거 |
| --- | --- | --- |
| 출처 구분 | 통과 | JSON의 `synthetic=true`, 보고서의 합성 자료 경고, artifact의 `fixture` 상태 |
| 재현성 | 통과 | 고정 시드 `20260901`로 두 번 실행한 파일 SHA-256이 일치 |
| 행 수 | 통과 | 합성 사용자 10행, 합성 기업 5행, 총 15행 |
| 재집계 | 통과 | CSV에서 독립 집계한 6개 지표가 JSON 대표 코호트와 일치 |
| 연산 범위 | 통과 | 확률은 0과 1 사이, 카운트는 분모를 초과하지 않음 |
| 노트북 실행 | 통과 | 모든 코드 셀 실행 완료, 오류 출력 0건 |
| 포터블 보고서 | 통과 | 캐노니컬 artifact 검증, 데스크톱 1440px과 모바일 390px 브라우저 QA 통과 |

## 중대한 한계

1. 분포의 사전 가정은 실측치가 아닙니다.
2. 사용자 행동, 인터뷰, 계약, 매출을 관측하지 않았습니다.
3. 결과는 인과 효과나 시장 수요를 증명하지 않습니다.
4. 대표 코호트는 설명용 샘플이며 발생 확률이 가장 높은 단일 결과라는 뜻이 아닙니다.

## 표현 금지 범위

사용자 10명 테스트 완료, 5개사 파일럿 진행, 유료 고객 확보, 사업성 검증 완료로 표현하면 안 됩니다. 사용 가능한 표현은 “실제 파일럿 전 의사결정 규칙을 점검한 합성 시뮬레이션”입니다.
