# 가상 데이터 품질 판정

판정: **한계를 명시하면 공유 가능**

이 자료는 제품 판단 기준의 재현성을 설명하기에는 충분하지만, 고객 수요나 사업성을 증명하는 근거로는 사용할 수 없습니다.

## 검사한 항목

| 항목 | 결과 | 근거 |
| --- | --- | --- |
| 출처 구분 | 통과 | JSON의 `synthetic=true`, 보고서의 가상 자료 경고, 분석 산출물의 `fixture` 상태 |
| 재현성 | 통과 | 난수 초기값 `20260901`로 두 번 실행한 파일 SHA-256이 일치 |
| 행 수 | 통과 | 가상 사용자 10행, 가상 기업 5행, 총 15행 |
| 재집계 | 통과 | CSV에서 별도로 집계한 6개 지표가 JSON 예시 결과와 일치 |
| 연산 범위 | 통과 | 확률은 0과 1 사이, 카운트는 분모를 초과하지 않음 |
| 노트북 실행 | 통과 | 모든 코드 셀 실행 완료, 오류 출력 0건 |
| 단일 HTML 보고서 | 통과 | 기준 분석 산출물 검증, 데스크톱 1440px과 모바일 390px 브라우저 QA 통과 |

## 중대한 한계

1. 분포의 사전 가정은 실제 관측값이 아닙니다.
2. 사용자 행동, 인터뷰, 계약, 매출을 관측하지 않았습니다.
3. 결과는 인과 효과나 시장 수요를 증명하지 않습니다.
4. 예시 결과는 설명을 위한 샘플이며 발생 확률이 가장 높은 결과라는 뜻이 아닙니다.

## 표현 금지 범위

“사용자 10명 테스트 완료”, “기업 5곳 파일럿 진행”, “유료 고객 확보”, “사업성 검증 완료”로 표현하면 안 됩니다. “실제 파일럿 전에 가상 데이터로 판단 기준을 점검했다”고만 설명할 수 있습니다.
