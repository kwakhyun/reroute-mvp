# REROUTE 포트폴리오 요약

## 한 문장 정의

오피스 이전이나 폐점 때 처분해야 하는 사무 자산을 사업자 정보와 처리 자격이 확인된 업체에 배분하고, 매각 대금, 폐기비와 운반비 절감액, 재사용률을 한 화면에서 비교하는 B2B 매칭 MVP입니다.

## 핵심 문제와 가설

자산 담당자는 매각가, 폐기비와 운반비, 재사용률과 수거 일정을 여러 문서에서 확인한 뒤 승인 자료를 다시 정리해야 합니다. 매각 대금, 폐기비와 운반비 절감액, 재사용률과 수거 조건을 한 화면에서 비교하면 확정 화면까지 이동하는 사용자가 늘어날 것이라고 가정했습니다.

## 구현한 제품 흐름

1. CSV로 자산 목록과 인수처 확인 자료가 포함된 입찰을 가져옵니다.
2. 자산 항목별 최소 매각 금액 기준과 제약 조건으로 가능한 배분을 계산합니다.
3. 매각 대금, 비용 절감액, 재사용률, 수거 횟수를 검토하고 확정합니다.
4. 확정된 배정을 수거 일정에 반영하고 외부 결제사의 입금과 지급 확인 상태를 남깁니다.

## 핵심 판단

- 반드시 구현한 것: 조직별 데이터 분리, 역할별 권한, 관계형 제약, 트랜잭션, 중복 실행 방지, 감사 로그, 행동 측정
- 생략한 것: 실제 결제, 복잡한 인수처 등록 절차, 실시간 채팅, 운송 최적화, 가설 검증에 필요하지 않은 AI 기능
- 검증 결론: 다음 검증은 기업 5곳 이내의 실제 파일럿으로 제한하고, 전담 개발 인력 투입은 보류

## 기술과 품질

Next.js 16, React 19, TypeScript, Drizzle ORM, libSQL과 Zod를 사용했습니다. ESLint, TypeScript, Vitest 커버리지, 실제 DB 경쟁 테스트, Playwright E2E 시나리오, 프로덕션 빌드와 의존성 감사를 자동화했습니다.

## 투명성

- 개인 기여도 100%
- 가상 데이터 분석 결과는 실제 고객 성과가 아님
- 실제 파일럿과 매출은 아직 검증하지 않음
- AI 코딩 에이전트는 구현과 감사를 보조했으며, 권한과 데이터 경계는 직접 검증
