# REROUTE 포트폴리오 요약

## 한 문장 정의

오피스 이전과 폐점 시 발생하는 유휴 자산을 검증된 수요처와 연결하고, 현금 회수와 폐기비 절감을 한 번에 비교하는 B2B 순환 자산 매칭 MVP입니다.

## 핵심 문제와 가설

자산 담당자는 매각가, 폐기비, 재사용 성과와 수거 일정을 서로 다른 문서에서 조율합니다. 개별 최고가보다 전체 순경제효과, 재사용률과 수거 조건을 한 제안에 보여주면 확정 의도가 높아질 것이라고 가정했습니다.

## 구현한 전체 여정

1. CSV로 자산 목록과 검증 근거가 포함된 입찰을 가져옵니다.
2. 자산군별 회수 하한과 제약 조건으로 가능한 배분을 계산합니다.
3. 현금 회수, 비용 절감, 재사용률, 수거 횟수를 검토하고 확정합니다.
4. 확정된 배정을 수거 운영으로 인계하고 외부 정산 확인 상태를 남깁니다.

## 핵심 판단

- 지킨 것: 조직 격리, 권한, 관계형 제약, 트랜잭션, 멱등성, 감사 로그, 퍼널 측정
- 생략한 것: 실제 결제, 복잡한 수요처 등록 절차, 실시간 채팅, 운송 최적화, 가설 검증에 필요하지 않은 AI 기능
- 검증 결론: 합성 시뮬레이션 결과, 제한적인 실제 파일럿은 진행할 수 있지만 유료 전환의 불확실성이 커 전담 개발 투자는 보류

## 기술과 품질

Next.js 16, React 19, TypeScript, Drizzle ORM, libSQL과 Zod를 사용했습니다. ESLint, TypeScript, Vitest 커버리지, 실제 DB 경쟁 테스트, Playwright 전체 여정, 프로덕션 빌드와 의존성 감사를 자동화했습니다.

## 투명성

- 개인 기여도 100%
- 합성 검증 수치는 실제 고객 성과가 아님
- 실제 파일럿과 매출은 아직 검증하지 않음
- AI 코딩 에이전트는 구현과 감사를 보조했으며, 권한과 데이터 경계는 직접 검증
