# REROUTE 4분 워크스루 구성

## 0:00–0:24 문제와 가설

“오피스 이전 현장에서는 매각가, 폐기비, 재사용, 수거 일정을 서로 다른 문서로 조율합니다. REROUTE는 이 정보를 하나의 추천 매칭안으로 바꿨을 때 확정 의도가 높아지는지 검증하는 MVP입니다.”

## 0:24–1:36 제품 흐름

“샘플 작업 공간은 오피스 이전 자산 214개와 검증 정보가 포함된 샘플 입찰 11개로 시작합니다. 현금 회수, 폐기비 절감, 재사용률, 수거 횟수를 한 눈에 비교하고, 자산별 배분과 파트너 검증 근거를 같이 볼 수 있습니다. 조건이 바뀌면 다시 계산하고, 권한이 있는 사용자만 매칭안을 확정합니다.”

## 1:36–2:16 풀스택 구현

“화면만 연결한 시안이 아닙니다. Next.js 서버 액션과 API, Drizzle ORM과 libSQL 스키마 16개, DB 세션, 조직 격리, 거래 멱등성, 버전 충돌 처리를 구현했습니다. 재계산과 확정이 동시에 발생해도 하나의 상태만 커밋되도록 실제 DB 경쟁 테스트로 확인했습니다.”

## 2:16–3:13 검증 시뮬레이션과 투자 판단

“이 수치는 실제 고객 결과가 아닙니다. 합성 사용자 10명과 합성 기업 5개사를 가정해 의사결정 규칙을 먼저 점검했습니다. 모든 기준을 동시에 충족할 추정 확률은 18.8%, 투자 규칙은 30.9%였습니다. 따라서 제한 파일럿은 진행하되 전담 개발 투자는 보류합니다.”

## 3:13–4:01 기여도와 인계

“이 개인 프로젝트의 기여도는 100%입니다. AI 코딩 에이전트는 구현과 감사를 보조했고, 권한, 트랜잭션, 스키마, 의사결정 수치는 소스와 테스트, 독립 재계산으로 직접 검증했습니다. 사업성이 확인되면 데이터 구조와 교체 지점을 인계하고 다음 가설로 이동할 수 있게 문서화했습니다.”
